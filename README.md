## 🎯 Project Overview

**e-Service** is a full-stack web application designed to manage home services and service workers.  
It provides a user-friendly interface, RESTful API, and file management capabilities (images & videos) to streamline service requests and interactions.

**Key Innovation:** Modular architecture with scalable backend and responsive frontend ensures smooth performance and easy future integration of ML modules or analytics dashboards.

## 🏆 Key Features

- **📝 User Management:** Register, login, profile management
- **📍 Location Services:** Track and manage service areas
- **📂 Media Uploads:** Support for images and videos
- **🔐 Authentication & Authorization:** Secure login & role-based access
- **💻 Responsive Frontend:** Vue.js + Vuetify for a modern UI
- **⚡ RESTful API:** Clean backend endpoints for integration

## 🛠 Tech Stack

| Layer | Technology |

## ⚙️ Installation

### Prerequisites
- Node.js >= 14
- MongoDB (local or cloud)
- npm (comes with Node.js)

### Quick Setup
```bash
# Clone the repository
git clone https://github.com/ayoub1999hannachi/e-service.git
cd e-service

# Backend setup
cd backend
npm install
npm run dev

# Frontend setup
cd ../frontend
npm install
npm run serve
````

## 🚀 Usage

* Access the frontend in your browser at `http://localhost:8080` (or the port shown by Vue CLI)
* Test API endpoints using tools like Postman or via the frontend interface
* Upload images or videos and see service worker profiles in action
